## 🚀 Featured Projects

## 🎮 Tetris

Stylized retro-inspired Tetris clone built with C++ and SFML.

The project recreates the atmosphere of old-school gaming systems while combining it with modern gameplay polish and custom technical solutions.

Features:
- custom UI framework
- keyboard-driven menu navigation
- settings menu with persistent configuration
- leaderboard system
- visual effects and shaders
- retro-inspired presentation
- modular game architecture

## 🚀 Until Last Asteroid

Arcade-style top-down space shooter built with C++ and SFML.

The game features keyboard and mouse controls, multiple enemy waves, a level progression system, score tracking, and simple menu/navigation systems.

Includes:
- wave-based enemy gameplay
- level progression system
- score system
- keyboard + mouse controls
- collision handling
- simple UI/menu system
